# Tasks: Tessera Format and Compiler

**Input**: [spec.md](./spec.md), [plan.md](./plan.md), [research.md](./research.md),
[data-model.md](./data-model.md), [contracts/](./contracts/), [quickstart.md](./quickstart.md)

**Prerequisites**: none. The constitution (4.0.1) already describes Tessera, so no amendment task
exists. Feature 006 (MCP) is not on this branch's base; its handoff checks are Phase 9.

Format: `- [ ] ID [P] [Story] Description (paths). Proof: what shows it works.` `[P]` means the task
touches different files from its neighbours and may run in parallel. Every task that changes code
ends with its own targeted test green and the formatter applied (`bun run fmt` on touched files).
No task edits an existing test only to make it pass; a change to an existing test is listed in the
pull request description.

**Process (owner-approved 2026-11-17)**: during implementation run only the feature's own tests,
`bun --bun run check` and `bun --bun run build`. The full unit suite, mutation tests, every browser
suite and the architecture review run once on the integrated batch before the merge (T050). Heavy
runs (the build, the scale test) use `sw-midgard-run -- <command>`.
